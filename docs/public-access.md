# 公网访问指南（樱花 frp + 自有域名）

> 目标：在外面也能打开家里的 IT 资产管理系统。
> 结论先说：**用樱花 frp 的「TCP 隧道 + 访问认证」最快能用；但想用自己的域名 + 浏览器不报警告，需要 ICP 备案。下面把每条路的代价讲清楚。**

---

## 零、开工之前：安全问题（已处理）

本系统原先**没有任何登录**，一旦暴露到公网：

- 任何人都能读取、修改、删除全部设备数据
- 任何人访问 `GET /api/settings` 都能拿到**智谱 API Key 明文**（实测确实泄露）

**已在 v1.1 修复**：

| 措施 | 说明 |
| --- | --- |
| 登录认证 | 除健康检查与登录接口外，所有页面和 API 都需要登录；未登录访问页面自动跳登录页，访问 API 返回 401 |
| 口令安全 | scrypt 加盐哈希存储，数据库内无明文；改密后所有旧会话立即失效 |
| 会话 | HMAC 签名 HttpOnly Cookie，默认 7 天，勾选「记住我」30 天 |
| 防爆破 | 同一 IP 15 分钟内失败 8 次锁定 |
| 密钥脱敏 | `GET /api/settings` 返回的密钥一律显示为 `abcd****wxyz`，掩码不会被回写覆盖真实值 |
| 初始密码 | 首次启动随机生成强密码，打印在控制台并写入 `data/admin-password.txt`（改密后自动删除） |

**登录账号**：首次启动控制台会打印，例如

```
用户名: admin
初始密码: XXXX-XXXX-XXXX
```

忘记密码：`node server/reset-password.js`（可加 `--user 张三 --pass 新密码`）。

> ⚠️ 上公网前请务必先登录并把初始密码改成你自己的强密码：**系统设置 → 账号安全 → 修改用户名/密码**。

## 一、关键前提：樱花 frp 的备案规则

摘自樱花 frp 官方文档（[网站备案](https://doc.natfrp.com/faq/beian.html)、[子域绑定](https://doc.natfrp.com/bestpractice/domain-bind.html)、[安全指南](https://doc.natfrp.com/bestpractice/security.html)）：

1. **HTTP(S) 隧道只能在标有「建站」的节点上创建**，而这些节点带自动备案防火墙，需要先通过「验证备案」。
2. **其他节点不提供人工过白，无法创建 HTTP(S) 隧道。**
3. 也就是说：**想用 HTTP 隧道 + 你自己的域名 `example.com`，这个域名必须完成 ICP 备案**（在[工信部](https://beian.miit.gov.cn/)备案，阿里云可代办，需有国内主机资源，通常 3~20 天）。
4. TCP 隧道不受此限制，但**没有自动 HTTPS 证书**。
5. 樱花 frp 给所有用户提供**免费的 `nyat.app` 子域名 + 免费 SSL 证书**，配「自动 HTTPS」后拿到的是**受信任的证书**，浏览器不报警告。

另外别忘了：**手机拍照识别必须在 HTTPS 下才能调用摄像头**（浏览器硬性要求）。所以选路时必须考虑证书。

## 二、三条可选路线

| 路线 | 域名 | HTTPS 证书 | 备案 | 手机相机 | 难度 |
| --- | --- | --- | --- | --- | --- |
| **A. 樱花 TCP 隧道 + 自签证书** | 可用自己域名 | 自签（浏览器警告，需点「继续」） | 不需要 | 需手点「继续访问」后可用 | ⭐ 最简单 |
| **B. 樱花 HTTP 隧道 + 自动 HTTPS** | 用 `xxx.nyat.app` 免费子域 | ✅ 受信任 | 不需要（用它的子域） | ✅ 完美 | ⭐⭐ 简单 |
| **C. 樱花 HTTP 隧道 + 自己域名** | `itam.example.com` | ✅ 受信任 | **必须备案** | ✅ 完美 | ⭐⭐⭐ 要等备案 |

**推荐顺序：先按 B 跑通（10 分钟能用，证书受信任、相机完美），等备案下来再升级到 C。**

## 三、路线 B：樱花 HTTP 隧道 + 免费子域名（推荐先做这个）

### 1. 实名认证 + 申请子域名
1. 登录 <https://www.natfrp.com> → 完成**实名认证**（用国内节点建站必须实名）
2. 进入 **管理面板 → 子域绑定** → **新建绑定**
3. 选 1~3 个单词作为前缀（二级部分不能自定义），创建一个 `xxx.nyat.app` 子域名

### 2. 创建隧道
1. **管理面板 → 隧道 → 新建隧道**
2. 类型选 **HTTP**，节点选标有「**建站**」的节点（可点「可建站」筛选）
3. 本地地址填 `127.0.0.1`，本地端口填 **8080**（本系统的 HTTP 端口）
4. **自动 HTTPS 设为「自动」** ← 关键，这样才能加载免费证书
5. 绑定域名：选刚申请的 `xxx.nyat.app`
6. 保存后**重启隧道**（改了配置必须重启才生效）

### 3. 本机启动 frpc
1. 打开 **SakuraLauncher**（已安装在 `C:\Program Files\SakuraFrpLauncher`）
2. 登录账号 → 找到刚建的隧道 → 点「启动」
3. 日志里看到下面这种就成功了：
   ```
   已从服务器为 xxx.nyat.app 加载证书 [CN = *.xxx.nyat.app, ...]
   隧道启动成功
   ```
   （首次签证书可能提示「证书签发中」，等几分钟）

### 4. 访问
```
https://xxx.nyat.app:<日志里给的端口>/        ← 管理端
https://xxx.nyat.app:<日志里给的端口>/m       ← 手机端
```

> 注意：樱花这类隧道通常是一个**高位端口**（如 `:10086`），不是 443。所以地址要带端口。

### 5. 同时让本机服务准备好
- 本系统要开着（双击 `start.bat`）
- 建议把 HTTP 端口固定为 8080（默认就是）

## 四、路线 C：用你自己的域名 `itam.example.com`

前置：**`example.com` 已完成 ICP 备案**（阿里云 → 备案），并在樱花面板**验证备案**通过。

1. **樱花面板**：隧道类型 HTTP，绑定域名填 `itam.example.com`，自动 HTTPS 设为「自动」
   - 如果面板要求填写自定义域名，就填它；同时把隧道的「绑定域名」设好
2. **阿里云 DNS**（你现在这个页面）新增记录：

   | 记录类型 | 主机记录 | 记录值 | TTL |
   | --- | --- | --- | --- |
   | **CNAME** | `itam` | 樱花给你的 `xxx.nyat.app`（或面板提示的目标域名） | 10 分钟 |

   > 也可以按面板提示填 **A 记录**指向隧道节点 IP，但**推荐 CNAME**：樱花迁移节点时会自动更新解析，你不用改。

3. **不要动你现有的 `@` 和 `www` 记录**（指向 203.0.113.10 的那两条），保持你原网站不受影响。
4. 等 DNS 生效（10 分钟内），访问 `https://itam.example.com:<端口>/`

> 如果面板提示「该域名未备案」 → 就是还没备案或备案未同步，先去阿里云备案。

## 五、路线 A：不通备案时的兜底（TCP 隧道 + 访问认证）

如果你暂时不想备案，也不想用 nyat.app 子域，可以用 TCP 隧道：

1. **樱花面板**：新建 **TCP 隧道** → 本地 `127.0.0.1:**8443**（本系统的 HTTPS 端口）
2. 在隧道的「**访问密码**」里设一个强密码（这是樱花 frpc 的**访问认证**功能，能挡住未授权 IP，强烈建议开启；还可配 TOTP 做 2FA）
3. **阿里云 DNS** 加 A 记录：`itam` → 隧道节点 IP（或 CNAME 到绑定域名）
4. 访问 `https://itam.example.com:<端口>/`
   - 因为走的是你自己的自签证书，**浏览器会报「不是私密连接」**，点「高级 → 继续访问」即可
   - 手机第一次也要点一次「继续访问」，之后相机就能用
5. 想消除证书警告：把自签证书 `certs/cert.pem` 安装到手机/电脑的信任凭据里（或用 C 路线拿受信任证书）

> 樱花文档明确说明：**访问认证只支持 TCP 隧道**；HTTP 隧道请用「HTTPS + Web 服务器鉴权」，也就是本系统自带的登录。

## 六、无论走哪条路，都建议做的加固

1. **改掉初始密码**，用 12 位以上大小写+数字+符号的强密码（樱花官方安全指南原话：`Passw0rd` 这种基本没有安全性）
2. **开启隧道访问认证**（TCP 隧道）或 **保持系统登录开启**（HTTP 隧道）
3. **不要把回收站里的敏感数据长期留着**，不需要就清空
4. **定期备份**：`POST /api/backup` 会在 `data/backups/` 生成快照；直接复制 `data/` 目录也行
5. **保持本机服务由你自己启动**（`start.bat`），并考虑做成开机自启，避免电脑重启后服务不在
6. 如果只是想自己用，**不暴露公网**其实更安全：用 Tailscale / ZeroTier 组虚拟局域网，手机装个客户端就能访问，无需备案也不需要证书（但要注意国内连通性）

## 七、排错清单

| 现象 | 排查方向 |
| --- | --- |
| 浏览器一直转圈 / 连接卡住 | 隧道没启动，或该 IP 尚未通过樱花访问认证（先浏览器访问隧道地址完成认证） |
| 提示「不是私密连接」 | 走的是 TCP + 自签证书，点「继续访问」；想消除就得用 HTTP 隧道 + 自动 HTTPS |
| 打开是 502 / 空响应 | 本机服务没起（确认 `start.bat` 窗口还在），或本地端口填错（HTTP=8080，HTTPS=8443） |
| 跳到登录页但登录失败 | 密码错，或失败次数过多被锁 15 分钟；用 `node server/reset-password.js` 重置 |
| 改了解析没生效 | DNS 有 TTL 缓存，等 10 分钟；CNAME 记录别和 A 记录同名冲突 |
| 手机能打开但调不了相机 | 必须 HTTPS；且自签证书要点过一次「继续访问」 |
| 隧道提示域名未备案 | 该节点是「建站」节点，必须备案；改用 TCP 隧道或 nyat.app 子域 |
