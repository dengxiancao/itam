一、系统概览#

本系统用来管理公司的 IT 资产：设备台账、组织归属、领用交接、保修跟踪、批量导入导出，并支持在手机上拍照识别设备品牌与 SN 号快速入库。

三个访问入口#

入口地址用途
管理端（电脑）http://<服务器IP>:8080/全部管理功能，建议用 Chrome / Edge
移动端（手机）https://<服务器IP>:8443/m现场拍照识别、扫码核对。必须是 https，否则相机用不了
公网访问https://itam.<你的域名>:<端口>/出差在外也能用，需由管理员部署

💡 手机首次打开自签证书的地址会提示「不是私密连接」，点 高级 → 继续访问 即可。

浏览器要求#

  • 电脑：Chrome / Edge / 火狐 等现代浏览器（不支持 IE）
  • 手机：系统自带浏览器、Chrome、Safari 均可；相机功能要求 https

三、账号与权限#

3.1 查看和修改自己的账号#

点右上角 账号：

  • 可以看到自己的用户名、姓名、角色、权限数量
  • 可以改姓名和密码（改密码需要输入当前密码）
  • 点「我的登录记录」可以看到自己最近的登录时间、IP、设备

⚠️ 修改密码后，你在其它设备上的登录会全部失效，需要用新密码重新登录——这是正常的安全机制。

3.2 四种角色能做什么#

角色适合谁能做什么
系统管理员IT 负责人全部功能：设备增删改、组织分类、Excel 导入导出、回收站、用户管理、系统设置
资产管理员资产专员设备增删改、组织分类、Excel 导入导出、回收站、查看审计日志；不能管用户、不能改系统设置
录入员现场录入人员查看设备 + 新增/编辑设备（含手机拍照录入）、导出 Excel；不能删除设备
只读领导 / 其他部门只能查看仪表盘、台账、组织、分类，不能做任何修改

权限是服务端强制校验的：即使绕过界面直接调接口，也会被拒绝（返回 403）。

3.3 忘记密码怎么办#

  • 找系统管理员，在「用户管理」里点「重置密码」，会生成一个一次性随机密码给你
  • 用这个密码登录后，系统会提示你立即改成自己的密码
  • 如果管理员自己忘了密码，需要在服务器上运行：node server/reset-password.js

3.4 管理员：用户管理#

左侧 👥 用户管理（仅系统管理员可见）

新建用户

  1. 点「＋ 新建用户」
  2. 填用户名（登录名）、姓名、选择角色、状态
  3. 设初始密码（至少 8 位，不能纯数字/纯字母；可点 🎲 生成随机密码）
  4. 保存后把用户名和密码交给对方

常用操作

解锁连续输错 5 次密码会锁定 10 分钟，可在这里提前解锁

查看登录日志：点「📜 登录日志」可以看到谁在什么时候、从哪个 IP、用什么设备登录成功或失败。

自助注册开关（在 系统设置 → 企业信息 里）：

  • 「允许访客自助注册」默认关闭（内网自用建议保持关闭）
  • 开启后建议同时勾选「注册后需管理员审核」，并把默认角色设为「只读」或「录入员」

五、手机端：拍照识别入库#

这是本系统最省事的功能：对着设备铭牌拍一张照，自动识别出品牌、型号、SN，核对后一键入库。

5.1 手机上怎么打开#

  1. 手机连接与服务器同一个 WiFi
  2. 浏览器打开 https://<服务器IP>:8443/m
  3. 首次会提示「不是私密连接」→ 点 高级 → 继续访问
  4. 浏览器询问是否允许使用摄像头 → 点 允许
  5. 顶部可以填「录入人」姓名（会记进操作日志，且会被记住）

如果一直提示打不开相机，多半是用了 http:// 而不是 https://——相机必须在 HTTPS 下才能调用。

两端可以互相跳转#

从哪 → 到哪入口
电脑端 → 手机端左侧菜单最下方「📱 打开移动端录入」
手机端 → 电脑端⭐ 两种：① 顶栏右上角的显示器小图标；② 首页最下方「回到电脑端管理后台」
两端 → 使用手册电脑端左侧菜单「使用手册」；手机端首页最下方「使用手册」

手机上只能拍照录入、扫码核对、查最近设备。改数据、看报表、导 Excel、管账号都要回电脑端——所以手机端特意放了两个回去的入口，不用再手敲网址。

5.2 拍照识别入库（完整流程）#

  1. 点 📷 拍照识别入库
  2. 把设备铭牌上的 SN 条码或文字放在取景框内，点白色快门按钮
  3. 出现照片预览，点 🔍 识别

> 📸 按下快门的那一刻，系统已经自动准备了 3 份照片（原图 / 识别图 / 缩略图）， > 识别成功后自动归档到这台设备名下，不需要你点任何保存按钮。

  1. 系统自动识别并填入：
字段说明
品牌显示置信度。若显示「由 SN 前缀推断」说明是根据序列号猜的，请核对
型号同上
SN 序列号关键字段，置信度最高，仍建议眼神核对一遍
  1. ⭐ 照片就在上面，对着比一遍：识别结果最上方是刚拍的那张铭牌照片缩略图，

照片在下、字段在上，一眼就能看出 OCR 有没有读错（例如 0 认成 O、8 认成 B）。

  • 点缩略图（或点右下角的 🔍）→ 全屏放大比对
  • 全屏里可以 双指捏合缩放 / 单指拖动，也可以点 ➕ 放大 / ➖ 缩小
  • 比完点「比完了」或右上角 ✕ 返回
  • 照片是识别时自动存到服务器上的，保存入库后会作为设备的铭牌照片一并归档
  1. 人工校正：
  • ⭐ SN 有候选就点候选：系统会拿同型号已录入的编号规律推断几个更可能的写法，

显示在 SN 下面（如 YLX2K4K1），点一下就替换，不用一个字一个字改。 视觉模型最容易把 L/1、O/Q、H/K 看错，这一步能省掉大半手工修改。

  • 自动纠正过会明确告诉你（「已自动去掉标签：SN1YLX22196 → YLX22196」），不会偷偷改
  • 其它字段识别不准就直接点进去改；置信度低于 60% 会标红，重点检查
  1. 补充信息：
  • 设备分类（有识别提示会自动选好）
  • ⭐ 分类专属字段：选好分类后会自动出现这个分类特有的字段。例如选「显示器」会多出 屏幕尺寸（24寸 / 27寸 下拉）、分辨率、接口类型；选「笔记本电脑」会出现 CPU / 内存 / 硬盘 / 屏幕尺寸等
  • 所属组织、使用人、存放位置、供应商、状态
  1. 点 💾 保存入库

🔁 识别不满意想重拍？ 底部有 重拍 按钮，点一下直接回到相机（不用回首页再点一次「拍照识别入库」）。

拍照预览页上的「重拍」同理。

为什么识别会更准了#

改进说明
图像分辨率 1600 → 2200px铭牌上的序列号只占几十个像素，多给点像素明显更准
送识别前先做灰度 + 对比度拉伸手机拍铭牌常偏灰、反光，拉伸后字和底分得更开（不动归档的原图）
提示词明确要求逐字符确认易混字符明确告诉模型 1/L/I、0/O/Q、8/B、5/S、2/Z、H/K 要分清，且不许「猜一个合理的」
同型号编号规律兜底同型号机器的编号长得极像（联想 ThinkCentre 全是 YLX 开头 8 位），拿档案一比就能把看错的字符纠回来
只保留取景框内的画面见下

📐 只保留取景框内的画面（省空间）#

拍照时只截取取景框里的那一块，框外的背景全部丢掉：

分辨率整帧实际保留省掉
1080×1920（常见手机竖屏）100%约 30%≈ 3.4 倍
2160×3840（4K）100%约 30%≈ 3.4 倍
1920×1080（横屏平板）100%约 27%≈ 3.7 倍

好处有两个：

  1. 省空间：归档的原图从一两 MB 降到两三百 KB，服务器磁盘和手机存储都省
  2. 识别更准：同样的像素预算集中在铭牌上，字符更清楚

📌 怎么保证不会把字裁掉：

- 取景框四周额外留了 15% 余量，铭牌稍微出去一点也能带上

- 拍完的预览页显示的就是裁好的那张图——如果发现铭牌被切了，当场点「重拍」就行

- 相机顶部提示也改成了「把铭牌放进框内（只保留框里的画面，请让字完整入框）」

用 🖼️ 从相册选图 时不裁——你选的那张图本身就是你要的，按屏幕比例硬裁反而会切掉铭牌。

保存成功后提示「已入库：资产编号」，设备出现在台账里。

⚠️ 如果 SN 已存在，会提示冲突，不会重复建两条记录。此时可以改用「扫码核对」去查那台设备。

5.2.1 📸 照片是自动归档的（不用点任何保存）#

按一次快门，系统会自动做三件事——全部默认开启，无需手动操作：

自动动作说明
① 存原图手机摄像头的完整分辨率（最高 4K）。归档进这台设备的设备详情，随时可放大看铭牌小字
② 存识别图最长边 1600px，OCR 识别和列表/详情预览用它，又快又清楚
③ 存缩略图最长边 320px，导出 Excel 时直接嵌进表格单元格

之后保存入库时，这三份就自动挂到该设备名下。看照片有两个地方：

  • 电脑端：设备台账 → 点设备 → 设备详情右侧「设备照片」，点图看原图，也能「下载原图」
  • 手机端：最近设备 → 点设备 → 顶部「📸 设备照片」，点图全屏放大，也能「存到手机」

💡 用「🖼️ 选图片」从相册上传时，你选的原始文件本身就是原图，系统照样自动归档。

顺便在手机里也留一份#

服务器上的照片归服务器管；如果你想在手机本地也有备份（发同事、离线看），系统默认就会自动存：

入口什么时候用存到哪

想进手机相册（而不是「文件」）：

  • iOS：用 📤 存到相册 → 选「存储图像」；或在照片上长按 → 选「存储到照片」

📌 浏览器不允许网页「偷偷」往相册写文件，所以第一次会弹一次「是否允许下载多个文件」的询问，

点允许之后就安静了。如果某次自动保存没反应，点一下照片下方的 💾 下载到手机 即可。

5.3 扫码核对 / 查询#

⭐ 提醒：扫码核对和拍照入库是两条完全独立的流程，互不影响：

📷 识别入库（首页大按钮）🔎 扫码核对（底部标签）
干什么拍铭牌 → OCR 认品牌/型号/SN → 新建一台设备扫二维码/条码 → 查出已有设备
快门按钮拍照并进入识别结果页只解条码，绝不会跳到入库页
取景框26% 高（够放铭牌）18% 高（够放二维码）

用法：

  1. 点底部 🔎 扫码核对
  2. 对准设备上的资产二维码或 SN 条码，自动识别
  3. 识别到资产二维码 → 直接打开该设备详情；识别到 SN → 在库里查找

二维码为什么以前扫不出来#

码里放什么，直接决定能不能扫出来：

码里放的内容二维码规格240px 显示时每格手机对着屏幕扫
网址 https://.../m/#/device/xxx版本 5 · 37×37 模块6.5 px❌ 太密，基本解不出
资产编号 MON-2026-0010版本 1 · 21×21 模块11.4 px✅ 同样距离一眼就过

以前码里放的是网址，所以一维条码（SN 条码）能扫、二维码扫不出来——这就是「只能识别条码」的原因。

现在设备详情和「打开二维码」弹窗都改成：

  • ⭐ 大码 = 资产编号（21×21）→ 手机 App 里「扫码核对」扫这个，好扫得多
  • 小码 = 网址（37×37）→ 手机自带相机扫这个，直接打开设备页

扫码后是先按资产编号查设备（/devices/lookup 同时支持 SN 和资产编号），查到就打开详情。

📌 贴在设备上的标签，建议印左边那个短码 + 把资产编号印成文字，双保险。

手机浏览器扫不了码？（iPhone / 部分浏览器）#

网页内扫码靠的是浏览器的 BarcodeDetector 能力，iPhone 的 Safari 没有开放这个能力（不是系统坏了）。 这时「扫码核对」页会明确提示，并给你两条路：

办法怎么做
⭐ 用手机自带相机直接扫设备上的资产二维码 → 会打开 /m/#/device/xxx → 直接进这台设备的详情页（不需要登录注册任何东西，用你已有的账号即可）
手动输入在「扫码核对」页输入 SN 或资产编号，一样能查
换个浏览器安卓 Chrome / Edge 支持网页内扫码

📌 二维码里放的地址必须是手机能访问的。管理端点「打开二维码」时可以选地址：

手机连同一个 WiFi 就选局域网，手机在外面就选公网地址。

系统会自动把 127.0.0.1 换掉，不会生成一个只有服务器自己打得开的码。

核对一致性：在设备详情页点「✅ 扫码核对这台设备」，再扫一次 SN，系统会告诉你扫描值与台账值是否一致，并把核对结果记进流转记录——适合盘点时用。

6.2 🔄 实时数据链接：让 Excel / WPS 自动刷新（推荐）#

痛点：每次都要重新导出一遍很麻烦。

解法：把表格软件接成系统的数据源，之后打开文件或点「刷新」就能拉到最新台账，再也不用导出。

先选对「取数地址」和「链接格式」#

Excel 对接 页的实时链接卡片上有两个下拉：

下拉怎么选
取数地址表格软件和服务器在同一台电脑 → 选「本机」最快；在另一台电脑 → 选「局域网」<br>⚠️ 别用「当前访问地址」里的公网 https 链接（自签证书 + 隧道认证页会导致取不到数据）
链接格式⭐ WPS 用户必须选「网页表格 · WPS / Excel 通用」<br>Excel 用户可选「CSV」，数字/日期会更规整

📌 WPS 的「自网站」只认网页里的 <table> 表格，不认 CSV——直接粘 CSV 链接会报

「无法获取数据，请确认网络链接是否正常或输入网址是否正确」。

这是 WPS 的机制问题，不是链接坏了。换成「网页表格」格式即可。

不确定链接对不对？ 点「📖 配置步骤」，在弹窗左下角点 「浏览器打开」——能看到一个表格页面就说明链接没问题。

配置步骤（一次性）#

  1. 选好地址和格式 → 在列表里点 📋 复制链接（想每个分类一个表，就复制对应分类的）
  2. Excel：菜单 数据 → 获取数据 → 自其他源 → 自网站

WPS：菜单 数据 → 获取数据 / 自网站

  1. 粘贴链接 → 确定 → 在导航器里选 Table（表格）→ 点「加载」／「导入」

想让「每个设备分类各占一个工作表」？#

系统提供了两种做法，推荐第 1 种：

做法 1：一次导入多张表（推荐）

点卡片上的 📋 复制「全部分类（多表）」链接——这条链接打开后是一个含多张表格的页面 （台式主机一张、显示器一张……）：

  • Excel：数据 → 自网站 → 粘贴 → 导航器里 勾选全部表格（Ctrl 多选）→ 加载 →

选「每个表放入新工作表」

  • WPS：数据 → 自网站 → 粘贴 → 表格列表里 全选 → 导入

做法 2：逐个导入（最稳，一定能成）

  1. 在链接列表里点「台式主机」的 📋 复制链接 → 数据 → 自网站 → 粘贴 → 加载到 Sheet1，

把 Sheet1 重命名为「台式主机」

  1. 换成「显示器」的链接，重复一次 → 放到 Sheet2 → 重命名为「显示器」
  2. 以后按 数据 → 全部刷新，所有工作表一起更新

点卡片上的 📖 多工作表怎么配 可以随时查看这两套步骤。

想先确认页面里有几张表，点弹窗里的「预览表格」。

让它自动刷新#

在生成的数据表上右键 → 表格 → 外部数据属性（WPS 里叫「数据范围属性」）→ 勾选：

  • ☑ 打开文件时刷新数据
  • ☑ 每 30 分钟刷新一次（按需调整）

配置一次，以后打开就自动是最新的。

几点说明#

事项说明
数据范围只读，只包含设备台账字段，不含任何密钥或账号信息
列的多少按分类走：每个分类的表格只带该分类配置的字段（显示器不会出现 CPU/内存/硬盘，主机不会出现屏幕尺寸），和 6.1 的分表导出一致
照片实时表里有 照片链接 列，单元格是可点击的「打开照片」（点一下浏览器打开图）。链接用的是局域网地址或你设置的「外部访问地址」，不会写成 127.0.0.1，所以同网段的电脑都能打开
想在实时表里直接看图导入后在表格里自己加一列，填 =IMAGE(照片链接那一格)（Excel 365 / 较新版 WPS 支持）。数据刷新时图片会跟着变——这是唯一能「自动更新 + 直接看图」的办法
「全部设备」那一行是跨分类的汇总视图，保留完整列，方便一眼看全
链接安全链接里带一个 token；点「🔁 重置链接」可让旧链接立即失效（照片链接是同一套 token）
数字变成科学计数法用 CSV 格式时可能出现；网页表格格式不会（但所有列都会是文本）
想改数据实时链接是只读的。要批量改数据，用导入功能（见 6.5）
导出点了没反应 / 浏览器报「网络问题」系统已改成「先由页面把文件取回来、再触发下载」，失败时会明确告诉你原因（HTTP 状态、空文件等），不会再是含糊的网络错误。若仍失败，试试 不含照片 缩小体积，或点 补缩略图

  1. 点 📁 选择文件导入，选填好的 Excel
  2. 预览：系统显示识别到多少行、匹配成功多少列、前几行数据的样子
  • 有「未匹配列」会黄字提示（这些列会被忽略）
  • 建议先勾选 仅预览（不写入数据库，先看结果） 跑一次
  1. 点 开始导入，完成后提示：
导入完成：新增 12、更新 3、跳过 1、失败 0
结果含义
新增库里没有这台设备，新建了记录
更新按 SN（或资产编号）匹配到已有设备，更新了它的信息
跳过勾了「仅预览」，或该行被标记为示例
失败该行有问题，会列出「第几行：什么原因」

两个选项

  • ☑ 自动创建缺失的组织/分类：建议勾选，省得先建组织
  • ☑ 遇到同 SN 时更新已有设备：建议勾选；取消则同 SN 的行会被跳过

七、组织架构与设备分类#

7.1 组织架构（🏢）#

支持无限层级：集团 → 公司 → 部门 → 小组。

  • 左侧是树形图，点组织名前的箭头可展开/收起
  • 右侧是表格，显示每个组织的类型、编码、负责人、设备数
  • 点「＋ 新增组织」新建；编辑时可以改「上级组织」来调整层级
  • 设备数统计：父组织会统计所有下级的设备

注意：删除组织前必须先处理它下面的子组织和设备（或勾选强制转移）。

7.2 设备分类（🗂️）#

  • 每个分类有：名称、编码、资产编号前缀、图标、主题色、专属字段
  • 资产编号前缀决定自动生成的编号，如「显示器」前缀 MON → MON-2026-0001
  • 专属字段：给该分类特有的属性，电脑端和手机端录入时都会自动出现
  • 已有设备的分类不能直接删除，需要先处理设备

专属字段支持 4 种类型

类型说明
文本自由输入
数字只能填数字
日期日期选择器
下拉选项只能从预设选项里选，避免各人写法不一致

怎么加一个下拉选项（以「显示器 → 屏幕尺寸」为例）

  1. 进入 🗂️ 设备分类，找到「显示器」，点「编辑」
  2. 在「专属字段」里找到 screen_size 那一行
  3. 类型选 下拉选项，右边会出现「选项」输入框
  4. 填入 24寸, 27寸（逗号分隔）
  5. 保存

设置好后：

  • 电脑端新增/编辑显示器时，「屏幕尺寸」变成下拉框
  • 📱 手机端拍照录入选到「显示器」分类时，也会出现这个下拉框
  • 想增减尺寸，改这里的选项即可，不用改代码

系统已预置：显示器 = 24寸 / 27寸；笔记本电脑 = 13.3寸 / 14寸 / 15.6寸 / 16寸。

如果某台设备的历史值不在选项里，下拉框会把它临时保留下来，不会因为改配置而丢数据。

效率小技巧#

  1. 电脑上大批量 → 用 Excel 导入；现场零星录入 → 用手机拍照
  2. 手机识别后务必扫一眼 SN，识别置信度再高也要人工确认
  3. 盘点时用手机扫码核对，会自动记录核对结果
  4. 打印资产二维码贴在设备上（设备详情页可打开二维码），以后手机一扫就能查
  5. 顶部全局搜索框支持 SN，客户报故障时直接粘 SN 回车定位
  6. 定期看仪表盘的「保修即将到期」，比翻 Excel 靠谱
